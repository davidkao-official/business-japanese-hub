報告時に事実と次の対応を短く伝える

進捗に遅れが出たときは、状況・影響・次の対応を分けて共有します。

無料架空のオリジナル教材です。すべての職場が同じ言い方をするとは限りません。

このレッスンのゴール進捗が遅れたときに、事実・見込まれる影響・次の報告時刻を伝えられる。

Plus

場面

社内プロジェクトで、資料の確認に想定より半日多くかかっている。今日送る予定だった草案は遅れそうだ。

確認できた事実を先に伝え、影響と次の報告時刻を添える。そうすれば、上司や同僚は予定を調整すべきか判断できる。

まず判断する

この遅れは、ほかの人の仕事に影響するか。わかっている事実とまだ確認中のことを分ける。

関係者には早めに進捗を伝え、影響の可能性、暫定の次の一手、次の報告時刻を示す。影響が未確定なら、見込みであることをはっきりさせる。

こう言う

上司へ・口頭またはチャット

キーフレーズ遅れの報告と次の一手

確認作業に想定より時間がかかっており、本日中に予定していた資料の共有が難しい見込み①です。影響範囲を確認し②、15時までに改めて状況をご報告します③。

  1. ①

    見込み：現時点の見通しであり、確定ではないことを示す。

  2. ②

    これから影響範囲を確認することを伝える。

  3. ③

    次に報告する時刻を約束する。

伝わる理由：原因を先に述べ、判断がまだ確定していないことを示したうえで、具体的な時刻で次の報告を約束しているから。

別の場面

例文次の確認時刻を調整している同僚へ

先方への確認がまだ終わっていません。回答を受け取り次第、今日の16時までに共有します。

まだ終わっていない確認を伝え、次に共有する時刻とその条件をはっきりさせている。

言い方と相手との関係

上司や、遅れの影響を受ける同僚には、確認できた情報を早めに共有する。チームで決まった報告の形や口調があれば、それを優先する。

未確認の影響を、確定したことのように言わない。緊急度や相手の役割に合わせて調整する。

書いてみる

例文を、自分の職場で起こりそうな場面に置き換えてみましょう。伝える事実、次の一手、相手に合った言い方を選びます。

ここに書いた内容は保存も採点もされません。

持ち帰る一文

進捗が変わったら、いまわかっている事実、起こりうる影響、そして次にいつ新しい情報を持って連絡するかを伝える。
